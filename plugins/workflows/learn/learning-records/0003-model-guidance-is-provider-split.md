# The two attached usage guides do not cover the same harness

The `mattpocock-superpowers-schema-model-effort` guide covers `minimal` and `standard`
(four schemas) in Claude model names, and agrees with the shipped subagent frontmatter
almost line for line. The `compass_artifact` guide covers the `advanced` level's eight
schemas — but for **DeepSeek V4 under OpenCode**, so its model ids, effort vocabulary,
prices, and its `reasoning_content` bug do not transfer to Claude Code at all.

**Consequence for teaching, as of when this was written:** the `advanced` eight had no
Claude-model recommendation beyond three pins in source (`design-gate`, `review-gate`,
`taste-preflight`), so lesson 12 taught the transferable rule plus that guide's
provider-independent depth classification and marked the rest a gap.

**Superseded 2026-08-28.** A third guide arrived with the real Claude table — see
[[0005-tier-guide-closes-the-model-gap]]. What survives from this record is the *reason*
the gap was left open rather than inferred: the refusal was correct, and it is why the
replacement is a citation rather than a guess. See [[0004-source-outranks-guides]].
