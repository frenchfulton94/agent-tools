# apple-studio Phase 10: Game Development on Metal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship two new skills, `apple-metal` and `apple-games`. Extend `apple-performance` and `app-release`. Distill all of it from a read-in-full corpus of about 780K words, and gate every snippet by compiling it in Swift, MSL, C++, or Rust. Check six behavioral claims at runtime, including a real notarization. Version bump to 0.11.0.

**Architecture:** The work runs as a pipeline. A deterministic crawler turns seed maps into a corpus manifest. Readers work through manifest slices in parallel, and each one writes a read ledger and distillation notes in our own words. Writers compose references from those notes, and new compile gates check every fenced code block. A small probe package (Swift, C++, and Rust hosts) checks the behavioral claims. A checkpoint after `apple-metal` lets the user decide whether `apple-games` ships in this phase.

**Tech Stack:** Python 3 standard library (pipeline scripts), bash (self-tests), Swift 6 / SwiftPM, Metal 4 and MSL 4.x (`xcrun metal`, Metal Toolchain 27A266a), metal-cpp with `clang++`, Rust 1.97 with `objc2-metal` 0.3.2, `xctrace`, `gpudebug`, `codesign` / `notarytool` / `stapler` / `spctl`, `pdftotext`, `claude` CLI (trigger evals), `bun` (catalog gates), Vale.

**Spec:** `authoring/apple-studio/docs/specs/2026-10-18-phase10-games-design.md`

## Global Constraints

- **Branch:** `apple-studio-phase10-games`, in a worktree cut from `main`. The `add-crossover-plugin` checkout's uncommitted work (`plugins/rust/`, `book-to-skill`, the README and marketplace edits) is never staged, copied, or committed by this phase.
- **Shorthand:** `AS=authoring/apple-studio`, `REC=$AS/records/2026-10-18-phase10-games`, `TMP=$AS/pipeline/tmp`. `TMP` is gitignored (`authoring/*/pipeline/tmp/`) and holds every downloaded page, PDF extract, the metal-cpp headers, and the cargo scratch crates. Each task writes its evidence to `$REC/task-N-<slug>/`.
- **Never commit Apple's, the MSL spec's, the Feature Set Tables', or the book's text.** References, notes, and ledgers are in our own words. Session transcripts go under `$REC/raw/`, which is gitignored.
- **Reading rule (spec § Reading discipline).** A page counts as read only when its raw text, saved in `$TMP/corpus/`, has been loaded completely with the Read tool, using offsets until EOF. `WebFetch` never counts as a read. Every manifest row gets exactly one ledger row.
- **No API name ships from memory.** If a symbol is in neither a fetched page nor the shipped SDK, it does not go in a reference.
- **Floor:** Apple silicon only. Metal 4 is the default voice. Metal 3 appears only under `## Maintaining older code: Metal 3`. Intel Macs and discrete GPUs are out of scope. The Metal 4 OS floor is **macOS 26.0 / iOS 26.0**: `MTL4CommandQueue`'s availability metadata, read 2026-10-18.
- **Language order:** Swift first. C++ and Rust appear only where they differ.
- **Every fenced code block in a new or edited reference is compile-gated**, or its fence is `text`, `bash`, `sh`, `console`, or `tsv`. Every ` ```swift ` / ` ```metal ` / ` ```cpp ` / ` ```rust ` block must compile clean.
- **Snippet binding names.** The Swift gate binds `device` to `any MTLDevice` (Task 2). `view` is already bound to a stub class, so an `MTKView` is named `metalView`.
- **Reference header** (CONVENTIONS.md format, plus the Task 2 directives), in this order: `> verified:`, `> sources:`, `> typecheck:`, then `> typecheck-metal:` / `> typecheck-cpp:` / `> typecheck-rust:` as the file needs them. Every new `apple-metal` and `apple-games` reference declares `> typecheck: macos 26.0`, or `> typecheck: macos 26.0, ios 26.0` when it carries UIKit or iOS-only snippets. Source short names: `metal-by-tutorials-5e`, `msl-4.1`, `metal-feature-set-tables-2026-05`.
- **Deviation from the spec, decided in planning.** The spec says Metal 3 snippets "carry their own lower target". The directive is per file, so Metal 3 snippets compile at their file's 26.0 floor. That still catches invented symbols, but it does not prove they run below 26.0. The `## Maintaining older code: Metal 3` sections say so in one line, and Task 13's spec append records the deviation.
- **Commit messages** end with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. The one-line messages below omit it for brevity.
- **Commits touching `plugins/`** must pass `bun test`, `bun run audit`, and `claude plugin validate . --strict`. Run them from the worktree root.
- **Version:** 0.10.0 → 0.11.0 in Task 13 only, in `plugins/apple-studio/.claude-plugin/plugin.json`. Tag `apple-studio-v0.11.0`.
- **External writes:** only Task 10's `notarytool submit`, and only after the user confirms the team named on screen. No other task sends anything to Apple, crates.io, or any other service. Downloads are fine.
- **Installs:** none. CMake stays uninstalled. If a step needs a system setting (Processor Trace), stop and ask the user.
- **Clean state at every task close:** `git -C ~/Projects/StudioFixture status --porcelain` is empty, `pgrep -fl 'MetalProbe|cpp-host|rust-host'` prints nothing, and `xcrun simctl list devices booted` lists no device.

- **Out of scope** (spec): SpriteKit, SceneKit, RealityKit, GameplayKit, third-party engines, visionOS and Compositor Services, general rendering theory, porting Windows games, art direction, Apple Arcade, tvOS, and Intel Macs.

- **Swift directive grammar:** `> typecheck: <target>[, <target>]`, where `<target>` = `macos <M>.<m>` | `ios <M>.<m>`.

  - `> typecheck-metal: metal<M>.<m>`: compile with `xcrun -sdk macosx metal -std=metal<M>.<m> -c <f> -o /dev/null`.

  - `> typecheck-rust: <toml dependency items, comma-separated>`: written verbatim under `[dependencies]` of a scratch crate at `<cache>/rust-gate/<sha256 of directive>/` (`edition = "2024"`), compiled with `cargo check --message-format short`. A dependency-resolution failure exits 2.
  - A file with blocks in a language but no matching directive exits 2. Any fence other than `swift`, `metal`, `cpp`, `rust`, `text`, `bash`, `sh`, `console`, or `tsv` exits 2 (`ungated fence language: objc`). The native gate does not compile `swift` blocks; `typecheck_snippets.py` owns those.
